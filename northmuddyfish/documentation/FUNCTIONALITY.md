# Theme Functionality

### MaskedInput
- It allows a user to more easily enter fixed width input where you would like them to enter the data in a certain format (dates,phone numbers, etc).
- [Readme](./../assets/js/vendor/maskedinput/README.md) &nbsp; | &nbsp; [Github](https://github.com/digitalBush/jquery.maskedinput)
- [Potential Replacement](https://nosir.github.io/cleave.js/)

### ValidForm
- ValidForm is a thin JavaScript wrapper on the HTML5 Form Validation features. It is very small at about 200 lines of code (7k, 5.6k compressed), and it has _no dependencies_. Nope, none.
- [Readme](./../assets/js/vendor/valid-form/README.md) &nbsp; | &nbsp; [Github](https://github.com/Pageclip/valid-form)

### Mmenu Light
- Mmenu light is the extremely small and lightweight alternative to the mmenu.js plugin. With a 6kb (minified) .js file and a 6kb (minified) .css file, you could not ask for a smaller disk footprint.
- [Readme](./../assets/js/vendor/mmenu-light/README.md) &nbsp; | &nbsp; [Site](https://www.mmenujs.com/mmenu-light/docs.html) &nbsp; | &nbsp; [Github](https://github.com/FrDH/mmenu-light)

### Slick Slider
- The last carousel you'll ever need.
- [Readme](./../assets/js/vendor/slick/README.md) &nbsp; | &nbsp; [Site](http://kenwheeler.github.io/slick/) &nbsp; | &nbsp; [Github](https://github.com/kenwheeler/slick/)

### Spotlight
- Spotlight.js is a small yet powerful JavaScript library that enables your visitor to view images and/or image groups in a fullscreen gallery popup.
- [Readme](./../includes/blocks/tab-module/spotlight/README.md) &nbsp; | &nbsp; [Site](https://nextapps-de.github.io/spotlight/) &nbsp; | &nbsp; [Github](https://github.com/nextapps-de/spotlight)

### Smoothscroll
- smoothscroll.js is a lightweight, configurable, Vanilla JavaScript polyfill for native smooth scroll using CSS scroll-behavior: smooth property.
- [Readme](./../assets/js/vendor/smoothscroll/README.md) &nbsp; | &nbsp; [Site](http://iamdustan.com/smoothscroll/) &nbsp; | &nbsp; [Github](https://github.com/iamdustan/smoothscroll)

### Hover Intent
- HoverIntent is a plug-in that attempts to determine the user's intent like a crystal ball, only with mouse movement!
- Handle: <small>hoverIntent</small>  &nbsp; | &nbsp; <small><i>Included with Core WP</i></small>
- [Site](https://briancherne.github.io/jquery-hoverIntent/)  &nbsp; | &nbsp; [WordPress](https://developer.wordpress.org/reference/functions/wp_enqueue_script/#default-scripts-and-js-libraries-included-and-registered-by-wordpress)

### Masonry
- Masonry is a JavaScript grid layout library. It works by placing elements in optimal position based on available vertical space, sort of like a mason fitting stones in a wall.
- Handle: <small>masonry</small>  &nbsp; | &nbsp; <small><i>Included with Core WP</i></small>
- [Site](https://masonry.desandro.com/) &nbsp; | &nbsp; [WordPress](https://developer.wordpress.org/reference/functions/wp_enqueue_script/#default-scripts-and-js-libraries-included-and-registered-by-wordpress)
